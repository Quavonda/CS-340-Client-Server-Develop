# CS-340-Client-Server-Develop
SNHU CS 340 portfolio featuring a MongoDB animal shelter database, Python CRUD module, and interactive rescue animal dashboard.
CS 340 Module Eight Journal Reflection

Writing Maintainable, Readable, and Adaptable Programs

Working on the Grazioso Salvare project helped me understand why keeping code organized matters, especially when different parts of an application need to work together. In Project One, I created a Python CRUD module to handle communication with MongoDB. When I started Project Two, I was able to reuse that module instead of writing the database connection and retrieval code again. This made building the dashboard easier because I could focus on the filters, data table, and charts without having to rebuild the database functions.

I learned that using clear variable names, comments, and separate functions makes code easier to understand and update. If I needed to change how the dashboard retrieves information, I could work on the CRUD module without rewriting the entire application. I could see myself using this same approach in future projects that involve managing customer information, inventory, or other records stored in a database.

Approaching Problems as a Computer Scientist

One thing this project taught me was how important it is to break a larger problem into smaller pieces. Grazioso Salvare needed a dashboard that could identify dogs suited for different types of rescue training. Instead of trying to build everything at once, I started with the database connection and worked my way through the interactive filters, data table, charts, and map. I tested each part to make sure it worked before moving forward.

This project was different from some of my earlier assignments because I had to think about how someone else would actually use the application. I ran into problems with syntax errors, getting the map to display correctly, and making sure the charts updated when different rescue filters were selected. Working through those issues helped me become more comfortable troubleshooting my code. In future projects, I plan to continue testing individual components, checking my results, and thinking about the client's needs before deciding how to build a solution.

The Role of Computer Scientists

Computer scientists use technology to solve problems, organize information, and develop systems that make work easier. This project showed me how programming can turn a large amount of data into something useful. Instead of having Grazioso Salvare search through animal shelter records manually, the dashboard allows users to filter dogs based on rescue training requirements and view the results through a table, chart, and map.

What stood out to me was how the database and dashboard worked together to make the information easier to understand. A project like this could help Grazioso Salvare spend less time searching through records and more time identifying dogs that may be suitable for training. It also showed me that being a software developer involves more than getting code to run. The application needs to be reliable, easy to use, and built around the problem it is supposed to solve.
